- #first-phone Built [[first-phone]] in one day. Releases 0.1.0 to 0.4.0, see [[first-phone/Changelog]].
	- Verified the existing Asterisk + web page setup on the home server; pinned the image; made the database survive rebuilds.
	- Rebuilt the admin page with a real sign-in and a keypad layout.
	- Tried one account per relative on the home server. Dropped it: every relative would have needed a VPN app as well as Linphone.
	- Switched to linphone.org: the server signs in as the house account, relatives use only the Linphone app.
	- Problems found and fixed, all written up in [[first-phone/Troubleshooting]]:
		- a phone signed in to the house account kept ringing and bypassed the allowed list
		- incoming calls did not reach the server over UDP
		- a semicolon in `pjsip.conf` silently cut a setting
		- encrypted call offers were refused with 488
		- a replaced config file was not seen by the container
	- Proved with real calls: a caller not on the list is hung up; an allowed caller rings the child's phone; the child's button rings the relative.
	- Added the Register page, username login, child's name and Settings.
	- Published the project on GitHub under the MIT license.
	- Still open: [[first-phone/Todo]]. The analog adapter has not arrived, so the real phone is untested.
