- Back to [[first-phone]]
- ## Required
	- **Always-on computer** with Linux and Docker
		- Tested: desktop PC, Ubuntu 26.04, wired to the router.
		- Fixed IP address (reserve it in the router).
		- No Linux box? Debian VM, see [[first-phone/Install]].
	- **Analog telephone adapter (ATA)** #untested
		- Cisco SPA112 - cheap used; no longer updated, keep it on the home network only; factory-reset on arrival.
		- Grandstream HT801 - current model.
		- Must register to a SIP server by IP with username and password, and send a single digit immediately.
	- **Corded analog phone**
		- Any. A photo phone with picture memory buttons is ideal; program each memory button to dial one digit.
	- **Cables** - Ethernet (adapter to router), RJ11 phone cable (adapter to phone).
	- **A smartphone per relative** with the Linphone app.
- ## Optional
	- Tailscale or another private VPN, to reach the admin page away from home.
	- A spare smartphone as a stand-in for the child's phone while testing.
- ## Not needed
	- Phone number, SIP provider, port forwarding, static public IP, domain name, FreePBX.
	- The internet provider's router phone port is locked to the provider and cannot be used.
