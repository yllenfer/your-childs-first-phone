- ## Server
	- Option A: existing Linux machine with Docker and the Compose plugin.
	- Option B: Debian VM in VirtualBox #untested
		- 2 GB RAM, 1 CPU, 10 GB disk.
		- Network adapter **Bridged**, not NAT, or the adapter cannot reach the VM.
		- Install Docker with `curl -fsSL https://get.docker.com | sudo sh`.
		- Host computer must not sleep.
- ## Steps
	- 1. Create the house account, see [[first-phone/Linphone]].
	- 2. `git clone https://github.com/yllenfer/your-childs-first-phone.git`
	- 3. `./scripts/setup.sh` - asks for the house username and password, writes `.env`, `manager.conf`, `pjsip.conf`, `db/astdb.sqlite3`, `webui-data/`. Prints the `kid` password.
	- 4. `docker compose up -d --build`
	- 5. Check `docker exec asterisk asterisk -rx "pjsip show registrations"` ends with `Registered`.
	- 6. Open `http://<server>:8099` and **Register** straight away. Whoever opens the page first becomes the owner.
	- 7. Settings: type the house Linphone username.
	- 8. Add relatives as buttons.
- ## Connect the phone #untested
	- Adapter: SIP server = the server's home IP, port 5060, UDP. User and auth ID `kid`. Password from `pjsip.conf`. Codec G.711.
	- Dial plan so one digit is sent at once: Cisco SPA `(x|600)`, Grandstream `{x|600}`.
	- Dial `600` for the echo test.
- ## Update
	- `git pull` then `docker compose up -d --build`. Settings are in ignored files and are kept.
- ## Backup
	- `tar czf first-phone-backup.tgz -C .. your-childs-first-phone` - contains passwords, keep it private.
